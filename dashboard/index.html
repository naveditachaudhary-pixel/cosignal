📄 policies.yaml Source Configuration

Editable rules format with zero-code hot-reload 
rules:
  - id: high-value-payment
    name: High-value payment
    actions: [create_payment, wire_transfer, refund]
    when:
      - {field: amount, op: gt, value: 10000}
    decision: require_approval      # allow | flag | require_approval | block
    severity: high

  - id: new-payee
    name: New payee verification
    actions: [create_payment, wire_transfer]
    when:
      - {field: new_payee, op: eq, value: true}
    decision: require_approval
    severity: high

  - id: customer-pii-access
    name: Customer PII guard
    actions: [read_customer_record, fetch_ssn]
    when:
      - {field: pii, op: eq, value: true}
    decision: flag
    severity: low

⚡ Cosignal Python SDK Setup

Integrate in 3 lines of code without altering your existing LLM prompting pipeline.

from cosignal import Cosignal

lens = Cosignal(agent="invoice-processor")

with lens.run(input="Pay Vendor Invoice") as run:
    # 1. Step recorder with automatic token pricing
    with run.step("llm", "extract", model="gpt-4o") as s:
        s.tokens(prompt_tokens=4200, completion_tokens=180)

    # 2. Guardrail check: Pauses if amount > $10,000 or unapproved vendor
    decision = run.check("create_payment", amount=invoice["amount"], vendor=invoice["vendor"], wait=300)

    if decision.allowed:
        with run.step("action", "create_payment"):
            execute_bank_wire(invoice)
    else:
        notify_slack_channel(f"Held for maker-checker sign-off: {decision.reason}")
