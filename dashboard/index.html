💡 How Cosignal Works

Cosignal applies the proven "maker-checker" / dual-control financial principle to autonomous AI agents.

1. Guard

Pre-Flight Check

Before executing sensitive actions like payouts, the agent asks Cosignal: run.check("create_payment", amount=...).

2. Approve

Maker-Checker Inbox

If payment exceeds $10,000 or payee is new, action pauses. Reviewers get a Slack ping and review in the Approvals Inbox.

3. Flight Recorder

Replay & Audit Trail

Every prompt, model call, token cost and human decision is preserved in an immutable audit log for compliance.

⚡ Integrate in 3 Lines of Python

The Cosignal SDK has zero external dependencies and ensures safe agent payouts.

from cosignal import Cosignal

lens = Cosignal(agent="invoice-processor")

with lens.run(input="Invoice from Acme Vendor") as run:
    # 1. Step tracking with token and cost attribution
    with run.step("llm", "extract", model="gpt-4o") as s:
        s.tokens(usage.prompt_tokens, usage.completion_tokens)

    # 2. Guardrail check: pauses if > $10,000 or new vendor
    decision = run.check("create_payment", amount=invoice["amount"], vendor=invoice["vendor"], wait=300)

    if decision.allowed:
        with run.step("action", "create_payment"):
            pay_vendor(invoice)
    else:
        notify_finance(f"Payment held: {decision.reason}")
